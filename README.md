# Открыть контакт в MAX (Bitrix24)

Локальное приложение: вкладка «MAX» в карточке контакта CRM. Для каждого телефона есть кнопка «Открыть в MAX».

## Установка
1. Выложите `index.html` на любой HTTPS-хостинг (GitHub Pages, Netlify, свой сервер).
2. Bitrix24 → Разработчикам → Другое → Локальное приложение:
   - тип: **клиентское** (без сервера);
   - путь обработчика и путь первоначальной установки — URL `index.html`;
   - права (scope): `crm`, `placement`.
3. Сохраните. Приложение само привяжет вкладку к карточке контакта.

## Настройка (блок CONFIG в index.html)
- `linkTemplate` — шаблон ссылки MAX. Я не смог проверить, какой именно формат ссылки по номеру телефона принимает MAX, поэтому сверьте его с документацией MAX и поправьте при необходимости.
- `maxFieldCode` — код пользовательского поля с профилем/ником MAX (например `UF_CRM_MAX`), если хотите открывать профиль напрямую.
- `placements` — куда встраивать. Для других мест (сделки, лиды) нужны другие placement и `crm.deal.get` / `crm.lead.get`.
